# SUIKA — ころころ、育てよう。

`index.html` をダブルクリックし、Edgeなどのブラウザで開いてください。HTMLファイル1つで動きます。インストール、サーバー、インターネット接続は不要です。

GitHub Pagesの公開元が `main` ブランチのルート（`/`）に設定されていれば、[公開サイトのトップ](https://president-code-ai.github.io/SUIKA-Game/)からゲームが開きます。

同じ果物をぶつけて、11段階の進化の最後にあるスイカを目指します。スイカ完成後も続けて遊べます。スイカ同士は合体しません。落とした直後の果物には猶予があり、果物が上の赤い線を約2秒越えたままだと終了します。

- マウス：左右に動かして位置を選び、クリックで落とす。
- タッチ：盤面で指を動かし、離して落とす。
- キーボード：盤面をクリックするかTabで選び、左右キーで移動、Space / Enterで落とす。
- 一時停止：P / Esc、または「一時停止」。別のタブやウィンドウに移ると自動で止まります。
- 音：初期状態はOFF。「音 OFF」を押すとブラウザ内で合成した効果音が鳴ります。
- やり直す：確認画面から再スタートできます。

ベストスコアはタブを開いている間だけ保持し、ページを再読み込みすると消えます。プレイ途中の自動保存はありません。外部通信、Cookie、localStorage、第三者の画像・フォント・ライブラリは使用していません。独自の果物イラストと簡易物理演算によるオリジナル実装です。

開発用検証は既存のNode.jsで `node --test tests/core.cjs tests/app.cjs` を実行します。追加パッケージは不要です。

実ブラウザ用の `tests/browser.cjs` は、既存Edgeを別プロファイルで起動します。ブラウザ起動の影響を確認・許可した場合に限り、`SUIKA_BROWSER_APPROVED=1` を指定して使います。ゲームを遊ぶための操作ではありません。検証結果と実行条件は `VALIDATION.md` に記録しています。
